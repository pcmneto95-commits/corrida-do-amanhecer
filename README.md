# Corrida do Amanhecer — Landing Page

Landing page responsiva para a **Corrida do Amanhecer**, um evento fictício de corrida de rua com percursos de 5, 10 e 21 km à beira da Baía de Guanabara, com largada antes do sol nascer. Projeto criado para o Desafio 01 (criação e publicação de uma landing page via GitHub Pages).

## 🧱 Tecnologias

- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 externo (Grid, Flexbox, variáveis CSS, `clamp()` para tipografia fluida) — sem CSS inline e sem tags `<style>`
- Google Fonts (Barlow Condensed + Karla)
- Sem JavaScript

## 🖼️ Sobre as imagens

As fotos da seção "Galeria" usam o serviço Lorem Picsum como placeholder (para o layout funcionar sem depender de fotos reais). Antes de considerar o projeto "de verdade", vale trocar pelos links de fotos reais do evento (ou de um evento real, se preferir usar um exemplo existente).

## 🤖 Uso de Inteligência Artificial

Usei a IA (Claude) como apoio no processo, não para gerar o projeto sem entender:

- Pedi ajuda para entender o enunciado do desafio e quebrar os requisitos em uma lista clara.
- Defini o tema (corrida de rua) e pedi que a IA propusesse um evento fictício plausível (nome, distâncias, data, local) para eu ter conteúdo real para trabalhar.
- Pedi a estrutura HTML semântica completa e o CSS externo responsivo, incluindo a paleta de cores e a ilustração SVG do amanhecer usada no hero.
- Usei a IA para revisar a acessibilidade (`alt` das imagens, hierarquia de headings, foco de teclado) e explicar cada bloco do código para eu conseguir apresentar e defender as escolhas.

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório no GitHub e envie os arquivos deste projeto.
2. No repositório, vá em **Settings → Pages**.
3. Em "Source", selecione a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde alguns minutos — o link do site aparecerá na mesma tela.
