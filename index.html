Uma corrida para ver o dia nascer

A Corrida do Amanhecer nasceu em 2019 com uma ideia simples: reunir corredores para largar ainda no escuro e cruzar a linha de chegada exatamente quando o sol aparece sobre a Baía de Guanabara.

Hoje é uma das provas mais tradicionais de Niterói, com percursos para quem está começando e para quem busca uma meia maratona com vista.
